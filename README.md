## 先定一件事：你的站要不要备案

这个问题的答案会直接砍掉一半选项，比纠结 2 核还是 4 核重要得多。

**需要备案的情况**：机房在中国大陆，比如江苏宿迁、湖北十堰、浙江绍兴、江苏镇江这些区域。这些机器的优势很实在——延迟普遍在 25ms 上下，国内用户打开快，而且不少区域自带高防。代价是域名要走 ICP 备案流程，快的话一两周，赶上材料反复补交就更久。

**不想备案的情况**：机房在中国香港、美国、韩国首尔、德国法兰克福。这些区域买完就能上，不用等审核。香港到大陆的延迟通常在 88ms 左右，美国洛杉矶 1 区大约 173ms，韩国首尔走三网直连约 60ms。做个人博客、测试站、面向海外用户的站，或者你压根不想碰备案流程的，这条路更省事。

一句话概括：**面向国内访客认真做站，能备案就备案；不想折腾或者面向海外，直接选免备案机房。**

## 建站看哪几个参数，别被"核多"带跑

关于配置，网上很多攻略把话说得太满。实际建站时真正会卡你的，是下面这几项：

**内存比 CPU 更容易先爆。** 一个装了 15 个插件的 WordPress 站，2GB 内存跑起来就有点悬；1核1G 只能撑轻量的静态展示站和日均几百 IP 的博客。4GB 内存是内容站比较舒服的档位。

**带宽分上行和下行，别只看一个数。** 下行决定访客下载你页面的速度，上行决定你往服务器传东西、以及服务器响应出去的速率。很多套餐标"100M"，实际指的是下行。

**流量计费制是个隐藏变量。** 雨云的云服务器分两类：不限流量型（配宽较窄，但流量随便用）和流量叠加型（带宽大，但有月流量额度）。流量型用完额度后会限速到 1M 或 5M，可以按 20G/20 元、100G/100 元、200G/180 元这类档位补流量。图片站、下载站、视频类站点要特别留意这条。

**硬盘能不能弹性扩容。** 雨云所有套餐的基础硬盘都不大（香港、美国机型基础 30GB 可扩到 2000GB，韩国机型 40GB），但支持随时加盘。SSD 云盘大约 0.3–0.4 元/GB/月，高效或机械云盘约 0.1 元/GB/月，不同机房有差异。建站初期买小盘、内容涨了再加，比一次买大盘划算。

**独立 IP 要不要另外买。** 这条最容易在结算页被忽略。雨云部分区域默认走 NAT 共享公网 IP，独立 IP 需要额外加钱：普通独立 IP 5 元/月，本地原生 IP 10 元/月，住宅 IP 25 元/月。国内某些机房的独立 IP 更贵（浙江、江苏高防区域因为捆绑独享防御，价格会高出不少）。**建站必须用独立 IP**，NAT 端口映射那套只适合学习 Linux 或内网穿透。

## 几个高频问题

**建站一定要买独立 IP 吗？**
要。NAT 共享 IP 做端口映射只能自己访问，域名解析和对外访问都不行。

**免备案机房会不会很慢？**
取决于机房。香港二区到大陆约 88ms，韩国首尔一区走三网直连约 60ms，都是国内访客可以接受的区间；美国洛杉矶 1 区约 173ms，延迟偏高，更适合面向海外用户的站或对延迟不敏感的下载类站。

**虚拟主机和云服务器怎么选？**
只有一个 WordPress 博客、不想碰系统维护，虚拟主机更省事也更便宜，支持宝塔面板。要跑多个站、装数据库、做定制环境，云服务器的灵活度是虚拟主机给不了的。

**配置选错了能改吗？**
可以。雨云支持按天补差价升级套餐、扩容云盘、迁移机房。不过迁移机房会涉及数据搬迁，别指望一键完成，重要站点提前备份。

**年付划算还是月付？**
从纯数学角度年付 7 折更省。但如果你是第一次用这家，建议先月付或试用一天实测，确认线路稳定、控制面板顺手之后，再续成年付。省下的那点钱，不至于让你赌上一年的使用体验。
